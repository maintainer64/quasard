# Автоматическое распознавание русского и английского

Для автоматического выбора языка каждой фразы используйте локальный whisper.cpp
с многоязычной моделью. Модели с суффиксом .en предназначены только для английского
и не подходят для auto; backend отвергает такой вариант при загрузке.

```toml
[asr]
engine = "whisper"
model = "whisper-base-q5_1"
model_path = "/app/models/ggml-base-q5_1.bin"
language = "auto"
threads = 2
device = "cpu"
```

Меняются только эти поля существующей секции ASR. Остальные параметры VAD
и записи можно оставить прежними. В режиме `auto` модель выбирает **только между
ru и en** для каждой записи; языковые токены остальных языков не участвуют
в выборе. Можно закрепить
`language = "ru"` или `language = "en"` без автоопределения. Предыдущая фраза
этой или другой колонки не используется как контекст.
Перевод на английский выключен: русская речь остаётся русским текстом.

## Модель

Закреплённый файл **59707625 байт**, SHA-256:

```text
422f1ae452ade6f30a004d7e5c6a43195e4433bc370bf23fac9cc591f01a8898
```

Источник:
https://huggingface.co/ggerganov/whisper.cpp/resolve/5359861c739e955e79d9a303bcbc70fb988958b1/ggml-base-q5_1.bin

В cloud этот файл добавлен в существующий models.lock/model-init: он проверяет
размер и SHA-256 и устанавливает модель до старта quasard. Другие установки
должны отдельно скачать файл в свой models volume и проверить указанный hash.
Модель не включена в Docker-образ. Обновление ASR требует нового образа и
перезапуска backend, SIGHUP и SIGUSR1 модели не меняют.

## Ресурсы и языки

В памяти находится один Whisper-контекст; распознавания сериализуются.
Пока одна колонка распознаётся, следующий запрос ждёт с поддержкой отмены.
Число CPU-потоков задаётся asr.threads (1–8). Отмена прерывает native inference,
а не только ожидание Go-обёртки. ASR-модель не загружается заново для каждой фразы.

В Docker Linux ARM64 с 2 CPU и ограничением 1,5 ГиБ проверен путь
Irina/hfc_female → Opus → Whisper: RU → EN → RU, отмена и следующий запрос.
На этих синтетических фразах длительностью 2,6–4,2 секунды ASR занимал около
2,4 секунды; пик cgroup составил 696610816 байт (около 665 МиБ), включая оба
Piper-голоса. Это измерение теста, не обещание задержки на любом CPU/микрофоне.
Публикуемые образы amd64/arm64 дополнительно проходят этот native fixture
перед публикацией, под теми же ограничениями.

Vosk остаётся прежним вариантом: engine="vosk", путь к соответствующей
языковой модели. При выборе Whisper Vosk-модель не загружается в память.

Для английской озвучки отдельно нужен tts.model_en (например hfc_female);
для русской можно оставить Irina. Выбор model_ru/model_en относится к LLM.
Whisper меняет входное распознавание, а не эти параметры.

Автоопределение может ошибаться на коротких именах, шуме или смешанной речи.
Переключение языка между фразами не гарантирует идеального распознавания
каждого слова в смеси языков. Слово активации остаётся настройкой самой колонки:
backend не меняет её локальный детектор. В результате ASR удаляется начальное
обращение как «Алиса», так и Alice.

Для диагностики включите [DEBUG](DIAGNOSTICS.md): будут видны engine, language,
время ASR, исходный и очищенный текст. Событие `Whisper language selected`
показывает фактически выбранный `language`, `mode=auto_ru_en` и `ru_probability` /
`en_probability` с device/request_id. Оценки нормированы внутри пары RU/EN:
это не оценка точности текста. Для закреплённого языка будет `mode=fixed`.
DEBUG намеренно содержит распознанную речь.
